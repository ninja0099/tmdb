# TMDB Collections — GitHub-backed catalog data

Static `data/*.json` files that back GitHub-sourced catalogs for the
[TMDB Collections Worker](../worker.js). Generated by
`.github/workflows/generate.yml`, served to the Worker via GitHub Pages.

## One-time setup

1. **Enable GitHub Pages** on this repo — Settings → Pages → Deploy from a
   branch → `main` / root. Your data will be reachable at
   `https://<you>.github.io/<repo>/data/<catalogId>.json`.

2. **Add repo secrets** (Settings → Secrets and variables → Actions):
   - `WORKER_ORIGIN` — your deployed Worker's origin, e.g.
     `https://tmdb-collection.freepg0099.workers.dev`
   - `TMDB_READ_ACCESS_TOKEN` — same TMDB v4 read token the Worker uses

3. **Add Worker secrets** (Cloudflare dashboard → your Worker → Settings →
   Variables, or `wrangler secret put`):
   - `GITHUB_PAGES_BASE` — `https://<you>.github.io/<repo>` (no trailing
     slash, no `/data`)
   - `GITHUB_PAT` — a fine-grained Personal Access Token scoped to just this
     repo, with `Actions: write` permission (needed so the Worker can
     trigger `workflow_dispatch` from `/save-default` and the "Refresh
     Catalogue" button)
   - `GITHUB_REPO` — `<you>/<repo>`
   - `GITHUB_BRANCH` — optional, defaults to `main`

## How it stays in sync

- **Saving in `/configure`** dispatches this workflow in `fill` mode —
  only catalogs with no existing data file get generated. Existing files
  are left untouched, so editing one list's sort order doesn't trigger a
  regenerate of the other 49.
- **The "Refresh Catalogue" button** in `/configure` dispatches in `full`
  mode — force-regenerates every GitHub-sourced catalog right now.
- **The daily cron** (03:17 UTC) also runs in `full` mode, as a freshness
  backstop independent of the Worker ever being touched.

## Marking a list as GitHub-sourced

Add `"source": "github"` to a collection/group/keyword-list entry in the
saved config (defaults to `"live"` — always a live TMDB call — when
absent, so nothing changes for lists you don't opt in).

## Manually running the generator

```bash
WORKER_ORIGIN=https://your-worker.workers.dev \
TMDB_READ_ACCESS_TOKEN=your_token \
MODE=full \
node scripts/generate.js
```
